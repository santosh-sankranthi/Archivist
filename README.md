# Archivist

**Graph Hacks 2026 submission (WeMakeDevs × FalkorDB) — work in progress.**

An engineering-intelligence agent with FalkorDB as its context layer: it turns a
codebase + its git history into a living graph, answers multi-hop questions with
traceable reasoning paths, takes actions, remembers across sessions, and
coordinates multiple agents over shared graph state.

Status: **M1 — ingest pipeline (in progress)**.

> This repository is being built during the Graph Hacks event window (Oct 15–18, 2026).
