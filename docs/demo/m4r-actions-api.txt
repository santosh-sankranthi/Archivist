=== POST /api/actions/{id}/complete round-trip (auth-gated, own repo) ===
Plan a review action, then close it; note the window closes (invalid_at set,
status -> done) and the supersede path writes a SUPERSEDES edge with a
distinct replacement (no self-loop).

$ plan_action("review url_for's public callers", type="review", targets=[{kind:symbol, file:src/flask/helpers.py, qualname:url_for}], evidence=[{kind:file, path:src/flask/helpers.py}])
-> fact:bd28f9e66873fa68

$ POST /api/actions/fact:bd28f9e66873fa68/complete  (anonymous, {"status":"done"})
-> 401 {"error":"unauthorized","message":"sign in to complete actions"}

$ POST /api/actions/fact:bd28f9e66873fa68/complete  (signed-in, own repo, {"status":"done"})
-> 200 {"id":"fact:bd28f9e66873fa68","status":"done","completed":true,"reason":null}

         "superseded_by":"fact:e573d3f2d080cc67","supersedes_edge":true,"reason":null}
